Основной результат проекта:

Создание датасета DiverseFemImages-STEM, предназначенного для исследования разнообразия представления женщин в STEM-профессиях в генеративных моделях изображений. Датасет должен содержать как индивидуальные рабочие сцены, так и командные взаимодействия, включая женщин разных возрастов, национальностей, типов телосложения, особенностей здоровья и стилей внешности.
